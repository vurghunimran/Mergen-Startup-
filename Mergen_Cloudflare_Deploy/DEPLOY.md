# Deploying Mergen (HTML/CSS/JS Version)

The project has been converted to pure HTML, CSS, and JavaScript. No build process, npm, or complex setup is required.

## Local Development
Simply open `index.html` in your browser.
For the best experience (navigation, etc.), usage of a simple local server is recommended but not strictly required.
Example (if you have python): `python3 -m http.server`

## Deployment
You can deploy this to any static hosting provider (Cloudflare Pages, Vercel, Netlify, GitHub Pages).

### Cloudflare Pages / Generic Static Host
1. Upload the project folder.
2. Build command: **Leave empty / None**
3. Output directory: **Root** (or leave empty)

That's it!
